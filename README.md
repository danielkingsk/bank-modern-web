# Neobank Landing Page

A modern, minimalist landing page for a fintech/neobank service, built with **React + Vite**, styled with **Tailwind CSS**, and written in **JavaScript**. Designed to convey trust, speed, and a clean digital-banking experience.

## ✨ Features

- ⚡ Blazing-fast dev environment and builds with Vite
- 🏦 Neobank-inspired UI: clean typography, soft gradients, card-based layout
- 🎨 Fully styled with Tailwind CSS utility classes
- 📱 Responsive design across mobile, tablet, and desktop
- 🚀 Optimized for performance and SEO-friendly structure

| Technology | Purpose |

## 📦 Getting Started

### Development

```
npm run dev
```

Open http://localhost:5173 in your browser to see the result.

### Build for production

```
npm run build
npm run preview
```

---

## 🎨 Styling

Tailwind is configured with a custom color palette and typography scale to match a neobank aesthetic (deep blues/blacks, accent gradients, rounded cards). Custom theme values live in `tailwind.config.js`.

---

## 🚀 Deployment

This project can be deployed on any static hosting provider (Vercel, Netlify, Cloudflare Pages):

```
npm run build
```

Then upload the contents of the `dist/` folder.
